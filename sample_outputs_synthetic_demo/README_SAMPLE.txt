Example outputs from the UPGRADED pipeline on SYNTHETIC data (no network in the build sandbox).
Run with a reduced config so it finishes quickly: gbt.n_estimators=30, lstm/transformer epochs=3,
walk_forward.min_train_days=2000 (5 folds), permutation_repeats=2.
These numbers validate that the pipeline runs and show the output format. They are NOT market findings
and the models are deliberately under-trained. Run `python run_all.py` for real results.
